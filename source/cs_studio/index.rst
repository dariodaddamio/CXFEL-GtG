Phoebus (CS-Studio)
===================

Phoebus (Control System Studio, CS-Studio) is the laboratory graphical user interface for
Compact X-ray Light Source (CXLS)/CXFEL: connect via Virtual Private Network (VPN), open the facility home screen, then use the
Global, Event, and Network areas as described in the pages below. Descriptions of Quartz and Event
Timing (EVT) chassis behavior and Input/Output Controller (IOC) scope are in :doc:`/osprey/index`;
the top-level orientation is :doc:`/index`.
