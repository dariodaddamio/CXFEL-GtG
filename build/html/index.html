Guide to Guides¶

Last updated: February 2026

Purpose¶

The Compact Free Electron Laser (CXFEL) requires high-fidelity time integration and synchronization between disparate hardware systems. CXFEL is working closely with a consultant/vendor, Osprey Distributed Control Systems (DCS), to develop such a system, which is known as the Data Acquisition System (DAQ), or more generally, the Event Timing (EVT) System. This document is meant to serve as a guide to the guides, a way of grasping the system as a whole, for development and testing purposes.

Introduction¶

The Data Acquisition System (DAQ), is composed of Event Generators (EVG) and Event Receivers (EVR). The EVG acts as the source of Time Zero (T0), which is used to synchronize the timing system with the radio frequency (RF) system and provide universal reference for all integrated diagnostics. The EVRs are distributed nodes that “listen” to the timing signal sent by the EVG and translate it into local actions through event codes.

The original proposal can be found here, but some main takeaways are:

  • Timing chain

    • GPS satellites provide an absolute time reference (atomic clock).

    • A GPS receiver (FS740) on the Biodesign roof locks to those satellites and outputs a very stable 1 pulse‑per‑second (1 PPS) plus a 10 MHz clock into the timing system.

    • Ideally, the EVG synchronizes to this clock and generates a global event stream that encodes when things in the machine should happen.

    • EVRs listen to that stream, decode event codes, and output hardware triggers/gates to local detectors, lasers, and other devices.

    • Detectors/DAQs record data in sync with those triggers, while IOCs handle configuration, timestamps, and data flow; EPICS provides the surrounding control and monitoring layer.

  • Event stream format (from NSLS II system)

    • Each event is carried as a 16‑bit word: the upper 8 bits are the event code (e.g. “start acquisition”), and the lower 8 bits are metadata (context like channel number).

    • Example: 0x0105 → event code 0x01, metadata 0x05 (binary 00000001 00000101).

    • There may be up to 256 (0-255) event codes, each with a unique meaning and metadata, with the exception of the predefined ones provided by Osprey DCS.
