Standard boot procedure¶

  1. Open a terminal.

  2. Start the GUI:

    • Run: phoebus.sh

  3. If you see extra/unwanted tabs, close them.

If the page you are left with is blank and has no label after “CS-Studio:”, click the blue home icon to reach the desired screen.
